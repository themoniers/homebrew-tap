# AppLinkly

Put an app running on your machine on the Internet in seconds, at `https://<name>.to.applinkly.com`.

- **No network setup** — no port forwarding, DNS, TLS certificates or firewall rules.
- **Live while you work** — the app keeps running where you build it; a change shows on refresh.
- **On when you want it** — stop the agent and every address goes offline.
- **Share safely** — protect an address with a sign-in, see who visits.
- **AI-friendly** — let your coding assistant put an app online for you, through MCP.

## Install

```sh
brew install themoniers/applinkly/applinkly
```

## Use

```sh
applinkly start                # run in this terminal (Ctrl-C to stop)

applinkly service install      # or run in the background
applinkly service login
```

More at [applinkly.com](https://applinkly.com).
